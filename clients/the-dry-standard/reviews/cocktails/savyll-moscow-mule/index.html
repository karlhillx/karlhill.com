Savyll Moscow Mule

Savyll's Moscow Mule is a Total Wine RTD. It is treated as formulated, not dealcoholized, because no source describes alcohol removal.

An RTD mule. No source describes a spirit that was later dealcoholized.

73/100

Is it actually dealcoholized?

An RTD mule. No source describes a spirit that was later dealcoholized.

Product overview

A Moscow Mule that never started as vodka is not a failure. It is a different product. No producer page naming a dealcoholized distillate was found, so the badge is No — formulated.

Ginger and lime, sweet, fizzy. Fine for the porch. Not a spirit review.

Tasting notes

Nose

Ginger and lime peel, bright and candy-adjacent.

Palate

Spicy ginger, sweet lime, carbonation doing the work a spirit would.

Finish

Short ginger heat. More soda than cocktail.

How to drink it

Iced, copper mug if you must.

Best for: The can you open instead of mixing.

Verdict

Ginger, lime, and fizz in a can. Not a dealcoholized vodka. A formulated mule, which is the honest category.
